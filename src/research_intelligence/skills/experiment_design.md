# Controlled Experiment Design Skill

## Principles

1. Change one major factor at a time.
2. Start from the validation-best implementation.
3. State a falsifiable hypothesis.
4. Define the expected metric effect before running.
5. Keep train/validation protocol unchanged.
6. Never inspect hidden-test results during research.
7. Distinguish:
   - scientific failure
   - implementation failure
   - noisy result
8. Prefer cheap experiments when expected information gain is similar.
9. Do not repeat failed experiments without new evidence.
