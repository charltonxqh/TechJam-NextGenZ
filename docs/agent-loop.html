Falsifier · autonomous ML research agent

One iteration: three branches of evidence, one decision, two stores

The agent fans out to gather evidence, converges on a single decision, and writes what it learned to two stores that feed the next iteration.

The three branches gather different kinds of evidence and terminate in two different stores: KnowledgeStore holds what is true about the problem — published methods, measured data facts — while Memory holds what was tried and what it scored, with provenance recording whether a human or the agent measured it. Both feed the next iteration, which is what makes the loop closed.
