PART 1

What the system is

Facts, not answersThe prompt carries the metric's invariance property, the reference ladder, and every ruled-out idea — but no conclusions. The agent derives findings by calling inspect() itself.
Test is physically absentThree layers: prep.py caches train+valid only, tools.py filters test dates at read time, guards.py fails the run if a test-shaped array appears.
Failures are dataEight failure classes, each with a recovery instruction fed back to the model, two repair attempts, then the hypothesis is abandoned and logged.

PART 5

The numbers, and what they mean

Validation figures come from the agent's own loop, which never sees test. Test is loaded once, in finalize.py, after convergence; every submission passes the official submit.py --check validator at 170,588 rows. The winning solution reproduced its recorded validation score to four decimal places on re-run. Per-seed noise is σ = 0.0008, so any delta below ~0.0016 is treated as unproven and re-measured across seeds before it is kept.
